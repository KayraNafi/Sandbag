# Security

Found a security problem? Please report it privately through
[GitHub's private reporting](https://github.com/KayraNafi/Sandbag/security/advisories/new)
rather than opening an issue. Include what you did and what you could reach.

This is a hobby project run for a small group of friends, so there's no bounty and
replies may take a few days. Test against your own copy, not sandbag.novaden.dev or
anyone's account.
